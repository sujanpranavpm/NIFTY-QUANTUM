## 1. Overview & General Adapter Architecture

This document establishes the formal schema contracts and conditional parser specifications for each data domain discovered in P2.2.8 and audited in P2.2.9–P2.2.9.3.

Every source adapter is a deterministic, offline transformation specification that:
1. Validates physical file signatures and header structures;
2. Maps heterogeneous raw exchange columns into standardized canonical internal schemas;
3. Enforces contract-level unit harmonization (contracts vs share-equivalents);
4. Performs exact decimal/paise tick validation and OHLC containment checks;
5. Attaches comprehensive immutable provenance metadata sidecars.

## 2. Domain K Adapter: Daily F&O Bhavcopy (Dual-Format Engine)

### 2.1 File Detection & Schema Signatures
The parser must detect schema format by physical header signature rather than relying exclusively on calendar dates:
- **Legacy Format Signature:** Header contains `INSTRUMENT`, `EXPIRY_DT`, `STRIKE_PR`, `OPTION_TYP`, `CONTRACTS`, `VAL_INLAKH`, `OPEN_INT`.
- **UDiFF Format Signature:** Header contains `TradDt`, `FinInstrmTp`, `TckrSymb`, `XprtnDt`, `StrkPric`, `OptnTp`, `TtlTradgVol`, `OpnIntrst`.
- **Conflict Rule:**
  - If a file dated on/after July 8, 2024 exhibits Legacy headers, or a file dated prior to July 8, 2024 exhibits UDiFF headers, the engine must tag the file with `SCHEMA_DATE_SIGNATURE_MISMATCH` and route it to `data/quarantine/schema/`.

### 2.2 Input vs. Output Schema Contract

```
+-----------------------------------+-----------------------------------+-----------------------------------+
| Canonical Field Name              | Legacy Input Field (Pre-UDiFF)    | UDiFF Input Field (Post-UDiFF)    | Target Data Type (Parquet)       |
+-----------------------------------+-----------------------------------+-----------------------------------+-----------------------------------+
| trade_date                        | TIMESTAMP (%d-%b-%Y)              | TradDt (%Y-%m-%d)                 | date32                            |
| symbol                            | SYMBOL (string)                   | TckrSymb (string)                 | string (category)                 |
| instrument_type                   | INSTRUMENT (OPTIDX/FUTIDX/...)    | FinInstrmTp (OPO/FTO)             | string (category)                 |
| expiry_date                       | EXPIRY_DT (%d-%b-%Y)              | XprtnDt (%Y-%m-%d)                | date32                            |
| strike_price                      | STRIKE_PR (float)                 | StrkPric (float)                  | float64                           |
| option_type                       | OPTION_TYP (CE/PE/XX)             | OptnTp (CE/PE or NA)              | string (category)                 |
| open_price                        | OPEN (float)                      | OpnPric (float)                   | float64                           |
| high_price                        | HIGH (float)                      | HghPric (float)                   | float64                           |
| low_price                         | LOW (float)                       | LwPric (float)                    | float64                           |
| close_price                       | CLOSE (float)                     | ClsPric (float)                   | float64                           |
| settle_price                      | SETTLE_PR (float)                 | SttlmPric (float)                 | float64                           |
| volume_contracts                  | CONTRACTS (int)                   | TtlTradgVol / LotSize (computed)  | int64                             |
| volume_shares                     | CONTRACTS * LotSize (computed)    | TtlTradgVol (int)                 | int64                             |
| open_interest_contracts           | OPEN_INT (int)                    | OpnIntrst / LotSize (computed)    | int64                             |
| open_interest_shares              | OPEN_INT * LotSize (computed)     | OpnIntrst (int)                   | int64                             |
| turnover_inr                      | VAL_INLAKH * 100,000 (computed)   | TtlTrfVal (float)                 | float64                           |
| board_lot                         | Inferred / Cohort reference       | NewBrdLotQty (int)                | int32                             |
| isin                              | ISIN (optional)                   | ISIN (string)                     | string                            |
+-----------------------------------+-----------------------------------+-----------------------------------+-----------------------------------+
```

### 2.3 Unit Normalization & Cohort Resolution
1. **ContractKey Construction:** `ContractKey = (symbol, expiry_date, strike_price, option_type)`.
2. **Lot Size Authority:**
   - In UDiFF files, `NewBrdLotQty` in the row is the observed authority (`estimated = False`).
   - In Legacy files, lot size is looked up against the verified contract cohort reference. If ambiguous, fallback to modal date regime with `estimated = True`. Unmapped cohorts reject from strict validation.

## 3. Domain H Adapter: Daily Cash Market (CM) Equity Bhavcopy

### 3.1 Input Detection & Series Filtering
- **Legacy Path / Signature:** `cmDDMONYYYYbhav.csv` inside `.zip`.
- **UDiFF Path / Signature:** `BhavCopy_NSE_CM_0_0_0_YYYYMMDD_F_0000.csv.zip`.
- **Mandatory Filter:** The adapter must filter rows to `SERIES == 'EQ'` (Legacy) or `SctySrs == 'EQ'` (UDiFF) to exclude debt, rights, warrants, and preference shares.

### 3.2 Canonical Output Schema Contract
- `trade_date` (`date32`): Trading session date.
- `symbol` (`string`): NSE trading symbol (e.g. `RELIANCE`, `TCS`).
- `isin` (`string`): 12-character international security identification number.
- `open_price`, `high_price`, `low_price`, `close_price` (`float64`): Traded prices.
- `prev_close_price` (`float64`): Prior session closing price.
- `volume_shares` (`int64`): Traded share quantity (`TOTTRDQTY` or `TtlTradgVol`).
- `turnover_inr` (`float64`): Total traded value in INR (`TOTTRDVAL` or `TtlTrfVal`).
- `total_trades` (`int64`): Number of transactions executed (`TOTALTRADES` or `TtlNbOfTxsExctd`).

## 4. Domain L Adapter: Hugging Face 1-Minute Expired Options Parquet

### 4.1 Input Signature & Licence Contract
- **Source Identifier:** `SRC-L1-HF-THETRADEMARKK`
- **File Format:** Snappy-compressed Apache Parquet.
- **Licence Obligation:** Licensed under `CC-BY-NC-4.0`. Output datasets must carry an immutable licence tag: `"CC-BY-NC-4.0 (Non-Commercial Research Only)"` and credit curator `thetrademarkk`.

### 4.2 Canonical Output Schema Contract
- `timestamp_ist` (`timestamp[ns, Asia/Kolkata]`): Standardized session timestamp.
- `symbol` (`string`): `NIFTY` or `BANKNIFTY`.
- `expiry_date` (`date32`): Option expiry date.
- `strike_price` (`float64`): Option strike.
- `option_type` (`string`): `CE` or `PE`.
- `open`, `high`, `low`, `close` (`float64`): 1-minute traded bar prices.
- `volume_shares` (`int64`): Traded volume in share-equivalents (contracts $\times$ lot).
- `volume_contracts` (`int64`): Computed as $\text{volume\_shares} / \text{lot\_size}$.
- `open_interest_shares` (`int64`): Open interest in share-equivalents.
- `oi_validity_flag` (`string`): `VALID_OBSERVATION` if $\text{OI} > 0$; `PRESENT_WITHOUT_OI` if $\text{OI} == 0$.

### 4.3 Validation Integrity Checks
- Session containment: Timestamp between `09:15:00` and `15:30:00` IST.
- Candle containment: $\text{low} \le \min(\text{open}, \text{close}) \le \max(\text{open}, \text{close}) \le \text{high}$.
- Zero-Imputation: Inactive minutes must remain unrecorded (`NO_TRADES`). Never synthesize bars.

### 5.1 Domain C: 91-Day T-Bill Auction Cut-Offs
- **Source Identifier:** `SRC-C1-RBI-DBIE`
- **Cadence:** Weekly (Wednesdays).

### 5.2 Domain M: Macroeconomic Series (Policy Rates & CPI)
- **Source Identifier:** `SRC-M1-RBI-DBIE`

- **Attribution:** Embedded citation to Reserve Bank of India.

## 6. Domain I Adapter: Point-in-Time Index Constituents

### 6.1 Input Architecture & Transformation
- **Source Identifier:** `SRC-I1-NIFTYIND-RECON`
- **Input Format:** Structured event table compiled from official semi-annual reconstitution press releases.
- **Event Schema:** `effective_date`, `symbol_added`, `isin_added`, `symbol_excluded`, `isin_excluded`, `corporate_action_reason`.
- **Membership Transform Engine:**
  The adapter expands the discrete event stream into an authoritative daily point-in-time constituent lookup matrix:
  $$\text{IsConstituent}(s, t) \in \{\text{True}, \text{False}\}$$
- **Strict Invariant:** For NIFTY 50, on every official trading day $t$:
  $$\sum_{s} \text{IsConstituent}(s, t) == 50$$
  Any date where constituent count $\ne 50$ triggers `CONSTITUENT_COUNT_CORRUPT` and fails closed.

## 7. Domain A Adapter: India VIX Historical Daily Data

### 7.1 Input & Normalization Contract
- **Source Identifier:** `SRC-A1-NSE-VIX`
- **Permissions Gate:** Axis 2 is `CONDITIONAL`. Staged file requires an explicit owner risk-acknowledgment record before normalization.
- **Canonical Schema:** `trade_date` (`date32`), `vix_open`, `vix_high`, `vix_low`, `vix_close` (`float64`), `prev_close` (`float64`), `pct_change` (`float64`).
- **Unit Warning:** VIX is an annualized percentage volatility index ($14.50 = 14.50\%$). The adapter must preserve raw levels and **must not scale by 100**.

## 8. Domain E Adapter: Participant-Wise F&O Open Interest

### 8.1 Input Structure & Row Invariant
- **Source Identifier:** `SRC-E1-NSE-CLEARING`
- **Input Header:** 15 columns across 4 client categories (`Client`, `DII`, `FII`, `Pro`).
- **Strict Row Sum Invariant:**
  $$\text{Total Long}_i = \text{FutIdxL}_i + \text{FutStkL}_i + \text{OptIdxCallL}_i + \text{OptIdxPutL}_i + \text{OptStkCallL}_i + \text{OptStkPutL}_i$$
  $$\text{Total Short}_i = \text{FutIdxS}_i + \text{FutStkS}_i + \text{OptIdxCallS}_i + \text{OptIdxPutS}_i + \text{OptStkCallS}_i + \text{OptStkPutS}_i$$
- **Reconciliation Flag:** Market-wide aggregate equality is logged as an informational diagnostic.
