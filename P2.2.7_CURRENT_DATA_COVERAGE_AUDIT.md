## 4. Execution-realism gaps that are *behaviour*, not missing files

These are recorded here so the audit is not mistaken for "data present ⇒ research correct":

1. **Liquidity gate is toothless.** `engine/options_execution.py` `min_exit_volume=1.0` compares against
   **1 share-equivalent** (≈ 1/lot of a contract), so it rejects essentially nothing. Volume data is present
   but not yet used as a real filter.
2. **Expiry settlement uses the last premium-bar close, not the official `SttlmPric`.** The correct value
   exists (2024+) but is not wired into settlement.
3. **No bid/ask/spread/depth** (B10–B12) — fills are bar-OHLC + assumed slippage bps; a real crossed-spread
   or impact-aware fill cannot be simulated at ₹0.
4. **Strict financial validation is fail-closed.** `readiness.py` `transaction_costs_verified` remains open
   because 2 slab-era `exchange_txn` rows (pre-2024-10-01) stay `estimated`; results on those dates are
   **modelling-only**, never a published verified figure. 11/12 gates pass per resolution.
