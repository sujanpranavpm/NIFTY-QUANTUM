## 1. The user-authorised decision (recorded verbatim)

1. **Adopt +15% target / −8% stop** as the default options research exit convention.
2. **Preserve orders_12's ratio-specific +16% target / −8% stop** (the 2:1 reward-risk
   honoured, per the adaptation-design ratio-preserving rule).
3. **Retain ±30%/30% only as a historical comparison configuration.**
4. **Hold-to-expiry remains a research benchmark, NOT the default exit policy.**

This closes the open decision referred to the user in P2.2.6 report §10 (option 1:
adopt the approved band). The errata stands: the ±30% band used by P2.2.3→P2.2.5 was an
unapproved implementation default (P2.2.5.1 audit); it was never a methodology choice.

## 2. What changed in the library (`nifty_quant/options/pipeline.py`)

| Change | Effect |
|---|---|
| `ExitConvention` defaults are now `stop_fraction=0.08`, `target_fraction=0.15` | the approved band is the actual default for any future adapter usage |
| New module-level `EXIT_POLICY: dict[str, ExitConvention]` + `APPROVED_DEFAULT_EXIT` + `approved_exit_for(sid)` | **central strategy-specific exit policy**: orders_12 → (+16/−8); orders_01/18/05/07 → (+15/−8); unknown strategy id raises `ValueError` (fail-closed, message names the covered ids) |
| `AdapterConfig.exit` is now `Optional[ExitConvention] = None` | `None` = "apply the central policy per strategy"; an explicit convention overrides the policy for every selected strategy (research overrides, historical replays) |
| New `AdapterConfig.exit_for(sid)`; `_record_signal` resolves rules via it | multi-strategy runs apply orders_12's exception **automatically** — callers no longer need the two-invocation concatenation pattern to avoid silently mis-banding it |
| `ExitConvention.__post_init__` validation | NaN/inf/negative/over-10/non-numeric/bool fractions and non-positive `max_hold_bars` raise `ValueError` at construction, never silently |
| `run()` rejects an empty strategy set (`ValueError`) | an empty selection can no longer masquerade as a completed run |
| Run `summary` records `exit_convention` (flat dict when uniform — shape-compatible with historical summaries — otherwise `{"per_strategy": …}`), plus new `exit_convention_per_strategy` and `exit_policy_applied` | every future run is self-documenting about the band each strategy actually traded under |

Exports added to `nifty_quant/options/__init__.py`: `EXIT_POLICY`, `APPROVED_DEFAULT_EXIT`,
`approved_exit_for`. No engine, cost, accounting, selection, bars or strategy file changed;
no thresholds, floors or methodology changed.
