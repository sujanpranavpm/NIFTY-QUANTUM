---

## 1. Status Classification Legend

Each investigated domain is classified under one of the mandatory milestone statuses:
- **`EXISTING IN REPOSITORY`**: Dataset already exists on disk in `data/` and is integrated/audited.
- **`CANDIDATE SOURCE FOUND`**: Verified free, legal, ₹0, no-account official source discovered with sufficient historical coverage.
- **`PARTIALLY AVAILABLE`**: Source found, but manual compilation is required, or historical depth is partial / structurally bounded.
- **`NO VIABLE FREE SOURCE FOUND`**: No genuine ₹0, legal, unauthenticated source exists (e.g. requires commercial payment or brokerage account).
- **`NOT REQUIRED FOR CURRENT RESEARCH`**: Out of scope for current active research objectives.

## 3. Deep-Dive Feasibility Assessments by Domain

### Domain A: India VIX Daily Historical Data
- **Mapping to P2.2.7:** Requirement C1 (Volatility and Derivatives).
- **Current Repo State:** MISSING (no code reads VIX; no data file cached).
- **Candidate Sources Evaluated:**
  1. *NSE India VIX Web Portal / JSON API (`nseindia.com`):* Authoritative source. Covers 2009-03-02 to present. Daily OHLC. Direct CSV download available on portal.
  2. *Yahoo Finance (`yfinance` ticker `^INDIAVIX`):* Convenient programmatic mirror. Covers 2009-01-02 to present. Daily OHLC.
- **Feasibility Verdict:** **FEASIBLE (Candidate Source Found).**
- **Research Impact:** Immediately unlocks India-VIX-conditioned volatility regimes (`validation/regime.py`), dynamic ATR/premium scaling, and high-volatility exit rules.
- **Constraint Compliance:** 100% free, no login or account required, no payment.

---

### Domain B: Contract-Level Implied Volatility and Greeks
- **Mapping to P2.2.7:** Requirements C2, C3, C6.
- **Current Repo State:** NOT STORED / NOT OBSERVED. Selection logic in `options/selection.py` operates strictly on observables.
- **Candidate Sources Evaluated:**
  1. *NSE Historical Public Archives:* Evaluated thoroughly. NSE publishes end-of-day traded prices, volumes, and open interest in bhavcopies, but does **not** archive historical contract-level IV or Greeks for free public download.
  2. *Commercial Tick Vendors (TrueData, GlobalDataFeeds):* Offer pre-calculated Greeks and IV surfaces, but require expensive recurring paid commercial licenses (>₹20,000/year).
  3. *In-Repository Black-Scholes Model Inversion:* Calculate contract IV using observed option premium (B1), underlying spot (A1), strike/maturity (B4), sovereign risk-free rate (Domain C), and dividend yield (Domain D).
- **Feasibility Verdict:**
  - *Observed Market IV/Greeks:* **NO VIABLE FREE SOURCE FOUND (Hard Blocker at ₹0).**
  - *Model-Derived IV/Greeks:* **FEASIBLE.**
- **Governance Mandate (Rule H5):** Model-derived IV and Greeks must be stored in a dedicated derived directory, clearly labelled `[MODEL-DERIVED / ESTIMATED]`, and never conflated with observed exchange data.
- **Key Clarification:** India VIX (Domain A) is **not** an input to Black-Scholes contract IV inversion.

### Domain C: Risk-Free Interest Rate Inputs
- **Mapping to P2.2.7:** Requirement C4.
- **Current Repo State:** MISSING (`config.py` carries no risk-free rate; `sharpe_ratio` defaults to `risk_free=0.0`).
- **Candidate Sources Evaluated:**
  1. *RBI Database on Indian Economy (DBIE — `data.rbi.org.in`):* Weekly 91-day Government of India Treasury Bill primary auction cut-off yields. Multi-decade historical coverage. Direct CSV/XLS export without authentication.
  2. *FBIL Overnight MIBOR / T-Bill Curves (`fbil.org.in`):* Daily benchmark rates.
  3. *CCIL Sovereign Zero Coupon Yield Curve (`ccilindia.com`):* Daily term structure.
- **Feasibility Verdict:** **FEASIBLE (Candidate Source Found).**
- **Implementation Recommendation:** RBI 91-Day T-Bill auction cut-off yields provide the most defensible, official sovereign short-term rate for NIFTY options (matching weekly and monthly maturities). Weekly values can be forward-filled across daily sessions.

### Domain G: Market Breadth (Advances / Declines)
- **Mapping to P2.2.7:** Requirement D6.
- **Current Repo State:** MISSING.
- **Candidate Sources Evaluated:**
  - *Reconstruction via NSE Daily CM Bhavcopies:* Standalone historical breadth CSVs are not provided by NSE as single continuous series. However, every daily CM Bhavcopy (`cm*bhav.csv.zip` or `BhavCopy_NSE_CM_*`) contains the universe of traded equities with `Close` and `PrevClose`. Computing `Advances = sum(Close > PrevClose)` across listed series reconstructs true market breadth with 100% mathematical accuracy.
- **Feasibility Verdict:** **FEASIBLE (Candidate Source Found).**
- **Research Impact:** Supplies classic market breadth indicators (Advance-Decline line, McClellan Oscillator proxies) to confirm index trend strength.

- **Feasibility Verdict:**
  - *Intraday 1m/5m/15m Bars:* **EXISTING IN REPOSITORY / PARTIALLY AVAILABLE** (short-DTE coverage, CC-BY-NC-4.0).
  - *Intraday Bid/Ask, Spread, Depth, Tick Tape:* **NO VIABLE FREE SOURCE FOUND (Permanent Hard Blocker at ₹0).**
- **Research Implication:** Point backtesting with bar-OHLC and slippage assumptions is supported; realistic crossed-spread execution and order-book impact simulation remain strictly impossible under ₹0.
